# Evaluation plan

## Offline evaluation

Choose metrics such as Recall@K, Precision@K, MRR, and NDCG@K based on the product objective and available relevance labels. Define query-level aggregation and handling of queries without judgments.

## Data splits and baselines

Document split strategy, label coverage, baseline systems, and confidence intervals.

## Online evaluation

If deployed, define guardrails and success metrics before an experiment; include latency, zero-result rate, and relevant business outcomes.
